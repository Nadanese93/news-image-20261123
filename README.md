A front page for Monday 23 November 2026, drawn procedurally in pure
Python 3 standard library — no images, no network, no dependencies.

**The day's news, in one image:** COP31 collapses in Antalya (the longest
COP ever ends with no pact after the final draft drops "fossil fuels");
Democrats take 258 seats in the US House, the biggest majority since 1992;
attacks on Hormuz shipping surge with three tankers hit; a Russian drone
hits a Kyiv flat, 3 dead; a candy-factory fire in Serang, Indonesia leaves
3 dead and dozens missing; Nepal's PM Shah meets Modi in New Delhi. Plus
sport in the footer: India 720/9 in Wellington, Liverpool 4–0 Man Utd.

Run it:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py   # writes out/entry.png (1024x1024)
```

Deterministic: two runs produce byte-identical PNGs.
